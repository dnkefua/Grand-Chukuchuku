# Chapter One pilot package

**The Courtyard Keeps Score** is a five-minute vertical opening pilot for *Grand-Chukuchuku*. It introduces Fiango, Zino, Gideon, Luc, Zino’s mother, the imaginary adult Grand-Chukuchuku, Nacking Bottle, and primary-school fee pressure.

Start with `Grand-Chukuchuku_Chapter_01_Pilot_Visual_Storyboard.pdf`, then use the script PDF or editable DOCX for the voice recording and animatic. The storyboard has 17 timed boards and runs exactly 5:00.

The screen action, dialogue, fee notice and exact chronology are proposed dramatic construction. The accompanying script marks the confirmed factual foundations and the safeguards that prevent this pilot from claiming a literal reconstruction.

The two images in `images/` are newly generated visual-development keyframes. The picture-board panels in `Reference_Assets/` are existing Chapter One visual development assets. They are all subject to the author-supplied baseline in `../visual-reference/VISUAL_BASELINE_V1.md`.
